# educode-prototipo
Este repositório contém o versionamento dos protótipos do projeto EduCode, desenvolvido no contexto do Projeto Integrador do curso de Engenharia de Software da Universidade Evangélica de Goiás.

Os protótipos, elaborados em baixa e média fidelidade, representam a estrutura das telas e o fluxo de navegação do sistema, com o objetivo de validar a proposta de solução sob a perspectiva do usuário e sua relação com os requisitos definidos.
